# NebulaVoice Mini App

## Підключення на Azure VPS

1. Налаштуйте HTTPS на окремому піддомені. Зворотний проксі має передавати
   `GET /` і `POST /api` на `http://127.0.0.1:8780`. Порт застосунку слухає лише loopback.
2. Зареєструйте Mini App для чинного бота в BotFather через `/newapp`.
   URL відкриття має вказувати на корінь HTTPS-піддомену. Використайте коротку назву
   `nebula` або вкажіть обрану назву у змінній середовища.
3. Додайте до середовища служби (або в чинний `.env` у каталозі проєкту):

   ```dotenv
   NEBULA_MINIAPP_URL=https://miniapp.example.com/
   NEBULA_MINIAPP_SHORT_NAME=nebula
   NEBULA_MINIAPP_PORT=8780
   ```

   Без `NEBULA_MINIAPP_URL` бот запускається у звичайному режимі.
4. Оновіть гілку Azure та перезапустіть службу.

   ```bash
   cd ~/NebulaVoice &&
   git pull --ff-only origin azure-vps &&
   .venv/bin/python -m py_compile main.py nebula_miniapp.py &&
   sudo systemctl restart nebulavoice &&
   systemctl is-active nebulavoice
   ```

5. Відкрийте кнопку під новою транскрипцією або відповіддю ШІ в ЛС і
   в групі. Перевірте повторне відкриття, сповіщення та лічильники.
   Помилки запуску застосунку записуються в журнал `nebulavoice`.

## Дані та ліміти

- Cloudflare D1 зберігає бонуси, історію, налаштування і рефералів в окремих
  таблицях. Під час першого відкриття з відповідного чату видається 10 000 токенів
  на користувача в ЛС або 2 000 на групу. Нульовий залишок теж зберігається і
  блокує повторну видачу.
- Бонус витрачається на текстовий ШІ після добового ліміту. Поточні тарифи
  та порядок скидання добових лімітів діють далі.
- Історія відображає до 50 нових власних транскрипцій у поточному чаті.
  Для статистики групи доступ перевіряється через Telegram. Telegram
  гарантує перевірку учасників через getChatMember, коли бот є адміністратором.
- Реферальне посилання прив'язує нового користувача при першому відкритті.
  Реферальна система веде облік запрошень.
- Особисті сповіщення про вичерпання ліміту вмикаються в профілі після
  надання Telegram-дозволу на приватні повідомлення.
