# NebulaVoice v0.2 — Test Edition
Python 3.11+. Install `pip install -r requirements.txt`. Copy `.env.example` to `.env` and fill in secrets privately on FadeHost. Start `python main.py`. Install system ffmpeg for video notes.

Set OWNER_ID to your numeric Telegram ID and BOT_TOKEN to the BotFather token. Use /test to select an account and model per chat. Groq accounts 1 and 2 each offer Whisper Large-v3 and Turbo; Cloudflare accounts 1 and 2 offer Whisper Large-v3 Turbo; Gemini uses GEMINI_MODEL (set to a currently available audio-capable free-tier model). Only owner messages are processed. No automatic failover. Use only authorized accounts in compliance with provider terms; disable paid usage. API availability and free quotas have not been live tested. Inform group participants before sending their audio to external services. Do not commit .env or credentials. Rotate exposed keys. OVH and HF removed for now.
